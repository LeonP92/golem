Package `internal/orchestrator/urlnorm` provides `Normalize(raw string) string`, an idempotent function that converts a git remote URL to a canonical lowercase form: scheme and host are lowercased, any trailing `.git` suffix and trailing `/` are stripped, and query string and fragment are removed. This canonical form is applied when Shems register their repo lists and when tickets are created, ensuring that `https://github.com/org/repo.git`, `https://github.com/org/repo`, and `HTTPS://GitHub.com/org/repo` all compare equal.
